# WELDAS - Proyek Web Order & Katalog

Repository ini berisi kode sumber untuk website proyek **WELDAS**.

## Struktur Folder & File
- `weldas1/index.html` — Halaman Utama / Beranda
- `weldas1/menu.html` — Halaman Catalogue / Menu Makanan & Minuman
- `weldas1/promo.html` — Halaman Info Promo
- `weldas1/faq.html` — Halaman Pertanyaan Umum (FAQ)
- `weldas1/style.css` — Berkas Desain & Tampilan (CSS)
- `weldas1/script.js` — Berkas Skrip Interaktif (JavaScript)
- `weldas1/images/` — Aset Gambar & Pembayaran QRIS

## Cara Menjalankan
1. Clone atau unduh repository ini
2. Buka folder `weldas1` di **Visual Studio Code**
3. Jalankan file `index.html` menggunakan ekstensi **Live Server**.WELDAS
